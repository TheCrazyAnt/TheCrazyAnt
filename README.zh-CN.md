## 作品证明

- **基于证据的 Agent 工具：** Agent Runtime Map 将确定性代码分析与可选的语义增强分开；LLM 可以描述已有结构，但不能虚构节点或连接。
- **业务流程自动化：** 商业发票生成器公开记录了解析流程、临时文件处理、浏览器端印章存储、Docker 部署方式和 32 个单元测试。
- **真实上线：** 发票工作流和个人网站都有可访问的线上版本，而不只是截图或设计稿。
- **工程透明度：** 项目文档明确写出架构、适用范围、已知限制、隐私行为和可复现的运行方式。
